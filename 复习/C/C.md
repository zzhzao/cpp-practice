## 原码反码补码
计算机硬件**只有加法器，没有减法器**。想要实现减法，必须把减法转换成加法运算。
原码直接相加无法正确完成减法，于是诞生反码作为过渡，最终使用**补码彻底解决问题**。

但反码依旧存在**两个 0**，没有彻底根除缺陷，只能作为中间产物，无法直接用于计算机运算。所以引出了补码。

计算机**内存中只存放补码**！
原码、反码只是人用来推导、理解的概念，硬件层面不存在。
## 大小端
小端模式：数据**低字节放在内存低地址**，x86 架构采用小端；
大端模式：数据**高字节放在内存低地址**，也叫网络字节序，网络传输统一使用大端。

大小端的判断：
```
#include<iostream>
using namespace std;
union myunion
{
	int a;
	char ch[4];
};
int main()
{
	myunion u;
	u.a = 0x12345678;
	if (u.ch[0] == 0x12)
	{
		cout << "大端";
	}
	else
	{
		cout << "小端";
	}
	return 0;
}
```

## 内存对齐
结构体：
为什么： 计算机 CPU 访问内存是**按块读取**（4 字节 / 8 字节），不是逐字节访问。
如果数据内存地址没有对齐，CPU 需要两次内存读取，再拼接数据，降低访问效率；
对齐到默认对齐树和该成员大小最大的最小值

联合：
取最大元素，对齐到默认对齐数的整数倍

## 程序的编译
预处理：进行头文件展开，宏替换，去注释，条件编译等
编译：检查语法生成汇编代码
汇编：将汇编代码翻译成机器码，生成目标文件
链接：将目标文件链接在一起，生成可执行程序

宏
c++中使用了内联函数来替代宏。
优点：**预处理阶段文本替换**，没有函数调用开销，不需要压栈、跳转；
缺点：宏在预处理阶段就展开，无法对宏代码进行调式。没有作用域，容易污染其他命名空间中的变量。由于是简单的替换，容易出现副作用，产生隐形bug.

## 关键字
volatile:**编译器**禁止对这个变量做优化读写，每次使用必须真实从内存读取，不能缓存到寄存器。(尽量减少访问内存，优先把变量放到 CPU 寄存器里。)

extern:用来**声明变量 / 函数**，告诉编译器：这个实体**定义在别的文件 / 别处**，当前只是声明，不要分配内存。

static: **内部链接**，只能本源文件使用，其他文件无法 extern 访问。在全局数据段上

const:修饰只读，不能通过该标识符修改对应内存.
如果类成员标记 `mutable`，const 函数内依然可以修改。const成员只能调用const函数。
